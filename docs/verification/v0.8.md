# Verificación v0.8 — Vista de imágenes

Fecha: 2026-11-15. Rama: `dev`. Implementación local completada; sin bump, tag ni
publicación. La publicación queda para el flujo `/release`.

## Suites

- `npm test`: 926 pruebas en 97 archivos aprobadas.
- `npm run test:coverage`: 926 aprobadas; statements 92.27%, branches 84.63%, functions
  91.02%, lines 93.98%.
- `npm run typecheck`, `npm run typecheck:e2e`, `npm run typecheck:node`, `npm run lint` y
  `npm run format:check`: aprobados.
- `cargo test --workspace --all-features`: aprobado, incluidas las pruebas que requieren
  sockets locales al ejecutar con el permiso de sandbox ya autorizado.
- `cargo clippy --workspace --all-targets --all-features -- -D warnings`,
  `cargo deny check` y `cargo audit`: aprobados.
- `npm audit --omit=dev --audit-level=high`: cero vulnerabilidades.
- `npm run build` y `cargo build --release`: aprobados.
- E2E nativo macOS/WebKit: 1/1 aprobado, historial de imágenes con tema claro/oscuro,
  inglés/español y viewport 940×600. Capturas revisadas: [inglés, tema claro](evidence/v0.8/images-en-light.png)
  y [español, tema oscuro](evidence/v0.8/images-es-dark.png). La prueba unitaria del lector
  stash cubre la comparación de imágenes guardadas.

## Presupuesto de lectura y rendimiento

- Clasificación, lectura y codificación base64 del presupuesto inicial de 2 MiB: **1.751 ms**
  en build optimizado (`cargo test --release -p gitcanvas-core
  measures_classification_of_the_initial_two_mib_budget -- --nocapture`).
- Lectura por IPC y serialización JSON de una imagen de 32 MiB: **133.437 ms** en release;
  carga base64 44,739,244 caracteres, JSON 44,739,352 bytes. Prueba
  `expanded_commit_image_round_trips_the_32_mib_payload_over_ipc`.
- Estos son tiempos de prueba local en este equipo, no garantías para otros equipos.

## Límites y gates pendientes

- Los parsers de cabecera son locales y acotados; ICO informa la primera entrada. El WebView
  controla la decodificación final; el soporte puede variar por plataforma.
- SVG se muestra aislado como imagen. Las imágenes mayores que los límites configurados se
  rechazan con metadatos; el techo de dimensiones es 40 MP.
- E2E nativo en Linux y Windows y validación con lector de pantalla real no se ejecutaron.
- Vite informa que el chunk principal de JavaScript supera el aviso configurado de 500 kB.
  `cargo deny` informa versiones duplicadas de `base64`; `cargo audit` conserva cinco avisos
  transitivos ya permitidos por la política del proyecto (paste, proc-macro-error, glib,
  rustix y tokio). Los comandos concluyeron correctamente y no se relajaron las políticas.
