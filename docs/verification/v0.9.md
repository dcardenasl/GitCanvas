# Verificación de v0.9: Contribuyentes y releases

Fecha de consolidación: 2026-11-22. Esta verificación cierra la implementación en `dev`,
no publica una versión. **Resultado global: parcial; no se declara PASS de la matriz.** La
verificación de casos y los límites corresponden a la evidencia de cada tarea y a los
informes de QA enlazados abajo.

## Límites y gates pendientes

- `V09-VERIFY-CR15-NATIVE-E2E`: recuperar espacio sin eliminar el `target/` compartido,
  construir el binario E2E, ejecutar WDIO, revisar las cuatro capturas y ampliar el flujo
  nativo para releases con un backend simulado local. Las dos compilaciones intentadas en
  CR-15 fallaron con `No space left on device`; WDIO no corrió.
- `V09-VERIFY-CR15-DOWNLOAD-PLATFORMS`: comprobar diálogo/renombrado y no sobrescritura en
  macOS, Linux y Windows. No hay evidencia de tres plataformas.
- `A11Y-LECTOR`: sesión real con VoiceOver, NVDA u Orca y recorridos manuales; no se infiere
  comportamiento de lector de pantalla a partir de roles DOM o pruebas de componentes.
- Casos de cerrojo, escritura/rename y proveedor se probaron localmente en macOS; no se
  ejecutó la matriz nativa de Linux y Windows para v0.9 (`V09-VERIFY-PLATFORM-MATRIX`). La
  evidencia anterior de CI no se atribuye a este cambio.
- No se hizo una consulta de releases ni una descarga contra GitHub real. Los tests de
  REST usan servidores locales.
- El caso 38 necesita una auditoría global reproducible de efectos de todas las acciones.
- El build de frontend registrado en CR-15 advirtió que el chunk principal supera 500 kB.
  No impidió ese build; queda como observación, sin cambiar el alcance de esta versión.
- Manifiestos y versiones siguen sin bump: no se creó tag, release ni instalador.
