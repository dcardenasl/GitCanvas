Fecha de consolidación: 2026-11-23. Esta verificación consolida la implementación v0.9 y
su complemento CR-17 en `dev`; prepara v0.9.0, pero no la publica. **Resultado global:
parcial; no se declara PASS de la matriz.** Los límites externos y la evidencia independiente
de CR-17 están registrados en el informe enlazado abajo.

## Complemento CR-17: sidebar y detalle central de releases

CR-17 ejecutó su matriz UIR-01–UIR-09 con pruebas unitarias/de estado, E2E nativo
macOS/WebKit y revisión de capturas. Los resultados detallados y el veredicto independiente
PARTIAL están en [`cr-17-qa.md`](cr-17-qa.md). E2E corrió en build 0.9.0 contra una API
GitHub sintética; cubrió lista/detalle/adjuntos, selección A→B→A, descarga fixture,
Escape/foco y Autores/Releases. Pasaron 12 specs/36 tests. Las 11 capturas inspeccionadas
están en [`evidence/v0.9-cr17/`](evidence/v0.9-cr17/). Después, el bundle instalado 0.9.0
consultó GitHub real para v0.8.0, abrió Full Changelog en Chrome y guardó dos veces un
adjunto `.sig` de 420 bytes (nombre original y renombrado) con SHA-256 coincidente. El
detalle está en [`seguimiento ARM64`](v0.9-macos-arm64-followup.md).

En esta consolidación pasaron `npm run test:coverage` (108 archivos, 999 tests),
typechecks frontend/E2E/Node, lint, formato, build frontend, `cargo fmt --all --check`,
Clippy estricto, `cargo test --workspace` (79 Tauri; 141 core y 1 ignorada; integraciones y
doc-tests), `cargo deny check advisories`, `npm audit --omit=dev --audit-level=high`,
`python3 .dcl/dcl.py doc-check` y `git diff --check`. El build frontend avisa del chunk
principal de 766.49 kB (>500 kB), sin fallar.

No se infiere verificación del lector de pantalla ni de diálogos/renombrado de descarga en
Linux y Windows a partir de esos resultados. A11Y-LECTOR fue aceptado por David como no
verificado; estos límites y los demás gates permanecen documentados en TASKS/README.

## Límites y gates pendientes

- `V09-VERIFY-CR15-NATIVE-E2E`: **PASS en macOS/WebKit**. Full WDIO (13 specs/41 tests)
  y el spec de autores/releases pasaron; cuatro capturas se revisaron. El diálogo real,
  navegación Tab nativa y accesibilidad de lector siguen en sus gates específicos; evidencia
  en [QA CR-15](cr-15-qa.md) y [seguimiento](cr-15-native-followup.md).
- `V09-VERIFY-CR15-DOWNLOAD-PLATFORMS`: diálogo y renombrado se verificaron en macOS con
  la app 0.9.0 y GitHub real; faltan confirmación de sobrescritura y pruebas del diálogo en
  Linux y Windows. La matriz automatizada pasó en los tres sistemas. Véase
  [seguimiento de matriz](cr-15-native-followup.md) y [smoke macOS](v0.9-macos-arm64-followup.md).
- `A11Y-LECTOR`: sesión real con VoiceOver, NVDA u Orca y recorridos manuales; no se infiere
  comportamiento de lector de pantalla a partir de roles DOM o pruebas de componentes.
- `V09-VERIFY-PLATFORM-MATRIX`: **PASS**. La corrida [`quality #45093960516`](https://github.com/dcardenasl/GitCanvas/actions/runs/45093960516), ejecutada sobre el commit `5cdc6dd` en `dev`, pasó tests de Rust, Clippy, bundles y WDIO nativo en Ubuntu, macOS y Windows. Esto aporta evidencia para CR-7, CR-9a/b, CR-10 y CR-11a/b; no sustituye el gate separado de diálogo/renombrado real ni pruebas con lector de pantalla.
- Los E2E de CR-17 usan una API GitHub local sintética. El smoke test instalado consultó
  GitHub live para v0.8.0; v0.9.0 aún no existe como release publicado y no se pudo
  comprobar su metadata/adjuntos publicados.
- El build de frontend registrado en CR-15 advirtió que el chunk principal supera 500 kB.
  No impidió ese build; queda como observación, sin cambiar el alcance de esta versión.
- Manifiestos y bundle instalado están en v0.9.0. No se creó tag ni GitHub Release. La
  compilación local no firmó updater artifacts porque falta `TAURI_SIGNING_PRIVATE_KEY`;
  la evidencia del bundle y sus límites están en el seguimiento ARM64.
