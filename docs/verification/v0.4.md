## Performance method

`GITCANVAS_E2E_FIXTURE_KIND=graph-performance` builds 10,000 linear commits and eleven
branch tips from a common older base using git fast-import, inside the owned temporary
fixture. The native test selects main, scrolls for 180 requestAnimationFrame callbacks,
counts mounted nodes/connections and writes a temporary JSON measurement. Timing is
reported rather than made a hardware-dependent CI assertion.

Initial macOS arm64 run at 1280×800: 60.24 fps over 2,988 ms; maximum frame gap 19 ms;
44 mounted nodes and 1,056 colored half-row paths. Backend logs: reference snapshot
5 ms, first 500-commit data page 46 ms. This is backend data latency, not an assertion
about complete process startup or end-to-end first paint. Second native measurement after the rendering correction: 60.54 fps over 2,973 ms,
maximum frame gap 20 ms, 44 nodes and 1,056 paths. Snapshot 12 ms; first data page
56 ms. Final rebuilt-binary measurement: 60.28 fps over 2986 ms,
maximum frame gap 18 ms, 44 mounted nodes and
1056 colored half-row paths. These are local results, not guarantees
for every machine. Final backend observations: snapshot 6 ms and first data page 45 ms.

The first screenshot inspection identified gaps caused by per-segment outlines covering
neighboring endpoints. Outlines now precede every colored connection; a regression test
checks the drawing layers and captures are repeated after rebuilding.

Temporary captures/reports stay outside the repository. Renderer health checks verify meaningful content, the GitCanvas project title, no Vite
overlay and no captured renderer errors/warnings during each session. New selector/title
assertions were corrected against the actual native DOM. Local-change polling now reads
a fresh DOM view atomically to avoid stale WebDriver element handles during refresh;
error capture remains enabled.

The WDIO plugin emits a cleanup
warning after sessions; assertions pass and the application uses no mock store. This
warning is not counted as a product failure or silently suppressed.
